## 1. 项目一句话

多项目管理个人看板（智能硬件产品模板），参赛「AI 工作台模板共创大赛」。Node.js 零框架后端 + 原生 JS/内联 SVG 前端，零 CDN，运行时依赖 `xlsx`（导入导出）与 `xlsx-js-style`（带样式 Excel 导出）。

## 2. 启动与部署（双实例）

```bash
npm install
node server.js          # 正式版：端口 5181（PORT=5181，真实数据，写操作需令牌 data/auth.token）
node server.js --demo   # 演示版：端口 5180（脱敏数据 + 免令牌，公网隧道指向它）
node watchdog.js        # 守护双实例：5180 演示 + 5181 正式，崩溃各自自动拉起 + 维护 Cloudflare 隧道
```

- **端口约定（勿改）**：5180 = 演示版（公网评委用）；5181 = 正式版（本机日常用）。
- 公网网址：每次重启变化，读 `data/tunnel-url.txt`（始终指向 5180 演示版，避免暴露真实数据）。
- 重启流程：`taskkill /IM node.exe /F` → `node watchdog.js`（自动拉起双实例）。
- 注意：`templates.json` 为两实例共享文件，demo 评委改模板会影响正式版模板。

## 3. 业务规则（用户明确要求，勿改回）

### 3.1 看板列宽
- 列宽 = 6 列正好占满看板：`.col { flex: 0 0 calc((100% - 80px) / 6) }`（80 = 5×16 gap）。
- **少于 6 个阶段：不铺满，按 6 列尺寸排列、右侧留白**；恰好 6 个阶段一屏放满；超过 6 个阶段横向滚动（列宽保持）。
- 历史教训：固定 264px 在常见视口 6 列会溢出滚动（被否）；均分铺满 flex:1（被否，因为 <6 阶段也铺满了）。**当前 calc 方案是用户认可的**。

### 3.2 日报/周报/月报 + AI 总结 = 全局项目
- 四个视图（daily/weekly/monthly/panorama）**不依赖左侧选中项目**，`render()` 用 `globalViews` 分支，无选中项目也渲染。
- 项目集合 = `reportProjects(mode)`：全部进行中 + **归档项目仅在归档发生窗口内**（日报=当天、周报=当周、月报=当月，按 `completedAt`）。
- AI 总结按钮始终显示，`aiSummarize(mode)` 传全局项目；后端 `/api/ai/summarize` 支持 `{projects, mode}` 全局组合总结 + `{project}` 单项目兼容。

### 3.3 项目信息选项
- **工程师姓名 / 认证标签：纯手填**（无下拉/选项池——已按用户要求移除，勿加回）。
- 项目类型 / 产品类型 / 项目等级：**可配置**（`data/options.json`，gitignore 排除）——新增/编辑/删除，新增弹窗只留 **WPS 风格色板**（无自定义颜色行）；等级 S/A/B/C/D/E/F 默认色。
- 工程师**类型**（硬件/结构/项目/测试工程师）：可新增/删除（`options.engineerTypes`），姓名行=类型标签+手填输入框；保存为 `engineers: {类型名: 姓名}`，兼容旧 `hardware/structure/project` key。

### 3.4 模板
- **无 JSON 模板导入**（已删除，accept 仅 .xlsx）；参考模版 Excel 导入 = 新建模板（取文件名、阶段作展示字段）。
- 模板卡片：可删除、可改名（`PUT/DELETE /api/templates/:id`）。
- 导出参考模版 = 由内置模板生成的**甘特方言 Excel**（`GET /api/templates/reference-xlsx?tplId=`）。
- 内置模板当前 4 个：智能门锁 / 智能手表 / 智能摄像头 / 智能音箱（「社区共享-智能台灯」已删）。

### 3.5 周报待办导出 Excel
- 导出为**真正 .xlsx**（`POST /api/reports/todo-export`，xlsx-js-style 生成样式）。
- 配色：标题/表头 = 矢车菊蓝·着色1·深度50%（`#1F3864`）白字；全表标准网格细线（`B4C7E7`）；隔行浅蓝（`F2F7FD`）；标题合并、项目列垂直合并；逾期红字 ⚠、里程碑 ⚑。
- 数据 = 当前周视图全局待办（与页面清单一致）。

### 3.6 左侧项目列表
- 分组可折叠：「正在进行 / 已归档」两组，折叠状态存 localStorage `kb-side-folds`。
- 项目卡片可**拖拽排序**（同组内），落位后 `PUT /api/projects/order` 持久化。

### 3.7 深色主题
- `.btn.primary` 用独立变量 `--btn-primary-bg/--btn-primary-fg`（浅色=深底白字、深色=亮底深字），勿用 `var(--dark)` 做按钮背景（深色主题下 --dark 是浅色，会白底白字）。

## 4. 甘特公式级联引擎（关键机制）

- 导入解析只认「甘特方言」：有 `内容` 列、无 `阶段` 列、日期在 **D/E 列**、`天数`在 **F 列**、单元格带 `WORKDAY.INTL(...)` 公式 → 捕获 `startRule/dueRule` → 甘特级联。
- 参考模版列布局：`任务|内容|负责人|开始|截止|天数|状态|备注`；首任务开始 `=WORKDAY.INTL($B$1,0)`（B1=项目开始日期），后续 `=WORKDAY.INTL(E上一行,1)`，截止 `=WORKDAY.INTL(D本行,F本行-1)`。
- `evalRule` 的 `off` 类型：base 是数字（F 列天数）时做数值偏移，不是日期（曾因把 F4-1 当日期导致级联 NaN，已修）。
- 状态列默认留空（写"未完成"会被 `/完成/` 误判已完成）。
