# 多项目管理看板 · 参赛说明

> 版本基线：**r51**（含 `--demo` 演示模式）；本次迭代新增：**AI 助手 / 移动端适配 / 模板共创（导入导出）**。本文档供比赛提报与评委试用参考。

## 一、作品定位

面向**智能硬件产品团队**的「多项目进度统一管理 + 自动化汇报 + AI 辅助」工具。
解决痛点：硬件项目阶段多（立项→设计→打样→测试→量产→上市）、跨项目进度靠人工拼 Excel、周报月报重复劳动、模板难以复用共享。

一句话价值：**把 7 类视图（看板/甘特/日历/全景/日报/周报/月度计划）、一套甘特公式引擎，以及 AI 任务生成/总结，装进一个零部署的网页里。**

## 二、评委体验（可运行 Demo）

- **公网访问地址**：见 `data/tunnel-url.txt`（当前：`https://voltage-roles-ever-simon.trycloudflare.com`）
- **免登录、免令牌**：演示实例以 `--demo` 模式运行，打开即玩，可直接新建 / 编辑 / 拖拽任务，无需任何账号
- **演示数据已脱敏**：7 个虚构智能硬件项目（智能台灯 / 智能手环 / 智能猫眼 / 智能闹钟 / 新品项目A / 迭代项目-演示版 / 新品项目B），不含任何真实产品信息

## 三、核心亮点（对应评分点）

| # | 亮点 | 说明 |
|---|---|---|
| 1 | **甘特图公式级联** | `B1`=项目开始，任务日期用 `=B1+1` 等公式联动；改开始日，后续任务按公式自动重算。支持 `WORKDAY.INTL` 工作日计算与 `$` 绝对引用 |
| 2 | **试产发布达成率** | 月度计划只统计「试产发布」维度，红（已延期）/绿（已完成）/蓝（进行中）/灰（未开始）状态徽章，直接对齐硬件团队最关心的节点 |
| 3 | **三档自动化汇报** | 日报（今日/逾期/到期）+ 周报（阶段泳道图 + 待办清单）+ 月度计划（勾选纳入、试产达成率），汇报从手工拼表变一键生成 |
| 4 | **xlsx 导入 + 参考模版** | 下载「参考模版」（由内置模版生成的 Excel，开始/截止含 `WORKDAY.INTL` 公式）→ 填写 → 导入即自动建立甘特级联；也支持任意 HUB 甘特方言 / 标准计划表自动识别 |
| 5 | **生产级加固** | 原子写（临时文件→rename）、写队列串行化、崩溃守护+开机自启、写操作令牌鉴权、10MB 请求限制、xlsx 升级 0.20.2、数据 git 版本回溯 |
| 6 | **AI 助手（新增）** | 自然语言描述需求 → 自动生成带阶段/工期/负责人的任务清单，一键创建项目；未配置 API Key 时走**模板规则兜底**，零配置也能演示；报告 / 月报页「AI 总结」一键生成结构化项目综述 |
| 7 | **移动端适配（新增）** | 窄屏汉堡菜单 + 抽屉式侧栏，PC / 手机同一套代码自适应，按钮触控区 ≥44px、输入框字号 ≥16px |
| 8 | **模板共创（新增）** | 模板可一键导出参考模版 Excel（含公式，填写后可从 xlsx 导入）；也可导入他人分享的模板 JSON（按 id 去重合并），形成社区模板生态 |

## 四、技术架构

- **前端**：原生 HTML/CSS/JS（无框架），7 视图单页应用，进度按工期加权计算；图标全内联 SVG，零外链
- **后端**：Node.js（零 Web 框架，仅依赖 xlsx），REST API + 自研公式引擎（`parseFormula` / `parseTerm` / `recalcProject`）
- **AI 客户端**：OpenAI 兼容协议，用 Node 原生 `https` 实现，**无额外依赖**；`base_url` / `model` / `api_key` 可在页面「AI 设置」中配置
- **数据**：JSON 文件落盘，纳入 git 版本管理，每次写入自动提交，可完整回溯
- **部署**：单进程 `node server.js`，可选 `--demo` 切换脱敏演示数据集；公网访问经 Cloudflare 快速隧道

## 五、本地部署

```bash
git clone <repo>
cd project-kanban
npm install            # 依赖已含 node_modules 亦可跳过
node server.js --demo # 脱敏演示模式（免令牌，加载 projects.demo.json）
# 浏览器打开 http://localhost:5180
```

真实数据模式（需令牌）：`node server.js`（写入需 `data/auth.token` 中的令牌，首次写操作页面会提示输入一次）。

## 六、数据安全

- 对外演示使用**独立脱敏数据集**（`data/projects.demo.json`），与真实业务数据（`data/projects.json`）**完全隔离**，互不影响
- 真实数据模式对所有写操作强制令牌鉴权；公网演示实例**仅挂载脱敏数据**，不存在真实信息泄露风险
- 演示实例的写操作不落 git（避免污染版本历史）
- `data/tunnel-url.txt`、`data/auth.token`、`data/readonly.flag` 已加入 `.gitignore`，不进版本库

## 七、功能演示清单（评委试用手顺）

1. **打开网址**（手机 / 电脑浏览器均可）→ 看到 7 个脱敏项目与首屏「今天要处理」
2. **AI 任务生成**：点右上「AI 助手」→ 输入如「做一个智能音箱降本项目，C 端、认证 CCC，硬件张工」→ 生成任务清单预览 → 点「创建项目」
3. **看公式联动**：进入任一项目 → 甘特图任务日期由公式联动（改项目开始日，后续任务自动重算）；月度计划看「试产发布达成率」徽章
4. **AI 总结**：报告 / 月度计划页 → 点「AI 总结」一键生成项目结构化综述（未配 Key 时由模板规则生成，仍可演示）
5. **模板共创 / 参考模版**：模板弹窗 → 「导出参考模版」下载 Excel（含日期公式）；「新建项目 → 从 xlsx 导入 → 下载参考模版」→ 在 Excel 填好任务与工期 → 导入，甘特图自动按公式级联排期
6. **移动端**：缩窄浏览器窗口或用手机打开 → 出现汉堡菜单，抽屉式侧栏，可正常操作
7. **（可选）接真实大模型**：「AI 设置」中填 OpenAI 兼容的 `base_url` / `model` / `api_key`，AI 生成即走真实模型
