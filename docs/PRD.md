# 多项目管理个人看板 · 产品需求文档（PRD）

> 版本：r51（加固版）　|　文档用途：培训 / 交接 / 需求基线  
> 应用定位：零依赖本地网页应用，面向智能硬件产品团队的**多项目进度与文档中心**

---

## 1. 产品概述

### 1.1 背景
智能硬件产品（手表 / 门锁 / 摄像头 / 音箱等）研发周期长、阶段多（NPI 六阶段）、参与角色杂。团队需要一个**轻量、可本地托管、可远程访问**的工具，把多个项目的进度、阶段、试产发布、日报周报、文档模板统一起来，替代散落在 Excel / 群消息里的碎片信息。

### 1.2 目标
- 一个看板管理多个产品项目，项目间互不干扰、可横向对比。
- 模板化建项：选一份产品模板即生成完整阶段与任务骨架，减少重复搭建。
- 多视角呈现：看板（执行）、甘特图（排期/公式）、日历（时间）、全景（统计）、日报/周报/月度计划（汇报）。
- 可远程访问、数据可备份回溯、运行稳定不丢数据。

### 1.3 价值
| 角色 | 获得价值 |
|---|---|
| 产品经理 | 全局掌握所有项目阶段与试产发布节奏 |
| 项目经理 | 排期公式级联、日报周报一键生成 |
| 工程师 | 任务责任到人、进度透明 |
| 访客/领导 | 只读模式分享，不担心被误改 |

## 2. 用户角色

| 角色 | 权限 | 说明 |
|---|---|---|
| 管理员（持有令牌） | 全部读写 | 首次运行自动生成令牌，存于 `data/auth.token` |
| 普通访客 | 仅只读（GET） | 通过公网链接查看，无法修改 |
| 只读模式访客 | 仅查看 | 管理员开启只读后，所有人（含自己）仅可查看 |

> 写操作（新建/修改/删除/导入/导出/只读切换/品牌图标）均须携带令牌；未携带返回 **401**。

## 5. 数据模型

### 5.1 项目（Project）
```json
{
  "id": "字符串",
  "name": "项目名称",
  "color": "#RRGGBB",
  "icon": "emoji 或图标",
  "type": "C端|B端|预研|迭代",
  "level": "S|A|B|C|D|E|F",
  "productType": "11 类之一",
  "cert": "认证标签(必填)",
  "engineers": { "hardware": "", "structure": "", "project": "" },
  "startDate": "YYYY-MM-DD",
  "tasks": [ /* 任务数组 */ ],
  "phases": [ /* 阶段定义 */ ],
  "done": false,
  "completedAt": "归档日期"
}
```

### 5.2 任务（Task）
```json
{
  "id": "字符串",
  "title": "任务名",
  "phase": "所属阶段",
  "startDate": "YYYY-MM-DD",
  "dueDate": "YYYY-MM-DD",
  "estimateDays": 整数,
  "done": 布尔,
  "owner": "负责人",
  "startRule": "公式(可选)",
  "dueRule": "公式(可选)"
}
```

> 说明：`category`、`summary` 字段已在迭代中移除，不再使用。

## 6. 接口需求（API）

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/projects` | 否 | 项目列表 |
| POST | `/api/projects` | 是 | 从模板新建项目 |
| GET | `/api/projects/:id` | 否 | 项目详情 |
| PUT | `/api/projects/:id` | 是 | 改名称/开始日期/类型/等级/产品类型/认证/工程师 |
| DELETE | `/api/projects/:id` | 是 | 删除项目 |
| PUT | `/api/projects/:id/tasks/:tid` | 是 | 改任务日期/工期/完成 |
| POST | `/api/projects/import` | 是 | xlsx 导入（base64） |
| GET | `/api/projects/:id/export?type=initial\|diff\|latest` | 否 | 导出 xlsx |
| GET | `/api/templates` | 否 | 模板列表 |
| GET | `/api/templates/reference-xlsx?tplId=` | 否 | 下载参考模版 Excel（含日期公式） |
| GET/POST | `/api/readonly` | POST 是 | 只读状态查询/切换 |
| POST | `/api/brand-logo` | 是 | 上传品牌图标 |
| GET | `/brand-logo.png` | 否 | 读取品牌图标 |

> 鉴权方式：写请求头 `X-Auth-Token: <令牌>`；GET 查询不受限。

## 7. 验收标准

1. 新建项目从模板生成，阶段与任务齐全，进度条正确。
2. 甘特图修改某任务开始/结束日期或工期，后续按公式实时级联更新。
3. 日报/周报/月度计划三类汇报口径符合 FR-43（周报无达成率；月度仅试产发布达成率）。
4. 未带令牌的写请求返回 401；带令牌返回 200；只读模式下写请求被拦截。
5. 进程被 kill 后 15 秒内由 watchdog 自动恢复。
6. 每次数据写入后 `git log` 可看到一次自动提交（数据有历史）。
7. xlsx 导入导出的解析与回环正常（0.20.2）。
8. 请求体 >10MB 返回 413。
