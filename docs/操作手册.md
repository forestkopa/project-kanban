## 一、快速开始（部署与启动）

### 1.1 环境要求
- 安装 **Node.js（LTS 版）**：https://nodejs.org 一路下一步。
- 本项目已内置 Node 运行时（`.../node/versions/22.22.2/node.exe`），无需额外安装也能跑。

### 1.2 启动方式（推荐 watchdog）
```bash
cd project-kanban
node watchdog.js
```
`watchdog.js` 会：探测 5180 端口，服务器挂了自动拉起；同时维护 Cloudflare 隧道（公网访问）。

> 仅本地调试也可直接 `node server.js`，但无守护，进程退出即停。

### 1.3 访问入口
| 方式 | 地址 | 适用 |
|---|---|---|
| 本机 | `http://localhost:5180` | 这台电脑 |
| 局域网 | `http://192.168.51.221:5180` | 同一 WiFi |
| 公网 | Cloudflare 隧道地址（存于 `data/tunnel-url.txt`） | 任何网络 |

### 1.4 开机自启
`watchdog.js` 已注册到「启动」文件夹（`start-kanban.vbs`），**登录 Windows 即自动运行**。无需手动启动。

## 三、常见操作（Step by Step）

### 3.1 新建项目（从模板）
1. 点右上「新建项目（从模板）」。
2. 选模板（手表/门锁/摄像头/音箱），填名称。
3. **必填**：项目类型、等级、产品类型、认证标签（不填会提示）。
4. 确认 → 自动生成阶段与任务骨架。

### 3.2 编辑项目信息
1. 点左侧项目名进入该项目。
2. 点项目标题旁「编辑」→ 改类型/等级/产品类型/认证/工程师。
3. 保存即落盘（写队列 + 原子写）。

### 3.3 看板任务操作
- **勾选完成**：任务卡勾选框。
- **拖拽**：按住任务卡拖到另一阶段列。
- **编辑/删除**：任务卡上的按钮。
- **设负责人/工期**：编辑任务时填写。

### 3.4 甘特图公式（核心）
坐标系（独立坐标行/列，用于公式定位）：
- 横坐标字母行：A / B / C / D（纯列标）
- 行号列：1, 2, 3 …
- 表头行（行1）：A1=公式框，B1=开始，C1=结束，D1=天数
- **B1 = 项目开始**（虚拟锚点，工具栏的「项目开始」输入框同步）

操作：
1. 点某任务行的「开始/结束」单元格 → 公式框显示当前公式（如 `=B1`、`=C4+1`）。
2. 编辑公式后失焦 → 转换为 xlsx 坐标并提交，后续任务按公式级联重算。
3. 改「项目开始」→ 全表按公式重算。
4. 改 D 列「天数」→ 结束日期按公式级联。

> 公式支持：`$` 绝对引用、`WORKDAY.INTL`、多段算术。循环依赖超 60 轮会告警。

### 3.5 月度计划（试产发布达成率）
1. 切到「月度计划」视图，可用月份选择器翻月。
2. 仅展示**本月有「试产发布」任务**的项目。
3. KPI：本月试产项目 / 试产发布达成率 / 延期试产 / 已完成试产。
4. 卡片：项目名 + 状态徽章（已完成绿/进行中蓝/未开始灰/已延期红）+ 试产发布日期。
5. 勾选 = 纳入本月计划，**本地记忆**（刷新不丢）。
6. 本月无试产发布显示空态。

### 3.6 xlsx 导入 / 导出
- **导入**：新建项目 →「从 xlsx 导入」→ 先「下载参考模版」（内置模版生成的 Excel，开始/截止含公式），在 Excel/WPS 填好任务与工期后选择导入；也支持 HUB 甘特方言、标准计划表自动识别、Excel 序列号日期。导入后开始/截止带公式的任务在甘特图自动级联。
- **导出**：右上「导出 ▾」→ 初版计划 / 差异对比 / 最新计划，下载 xlsx。

### 3.7 只读模式（分享前必开）
1. 点右上「🔒 开启只读」。
2. 确认后所有人（含自己）只能查看、不能修改。
3. 分享公网链接给同事前务必开启，防止误改。
4. 再点「🔓 解除只读」恢复正常。

## 四、令牌与鉴权（重点）

**为什么有令牌**：任何能访问网址的人默认都能改数据。加令牌后，只有持有者能写，其他人仅能看。

- 令牌首次启动自动生成，存于 `data/auth.token`（启动日志也打印）。
- **网页端**：首次执行写操作会弹窗要求输入令牌，输入一次后自动记住（localStorage `kb-token`），后续免输。
- **查令牌**：打开 `data/auth.token` 文件复制即可。
- **换令牌**：删除 `data/auth.token` 后重启服务器，会生成新令牌。
- ⚠️ 令牌等同于账号钥匙，**勿随公网链接外泄**；分享只读链接即可。

## 五、开机自启与守护（运维）

| 组件 | 作用 | 文件 |
|---|---|---|
| watchdog.js | 探测 5180，挂了 15s 内拉起；维护隧道 | `project-kanban/watchdog.js` |
| start-kanban.vbs | 登录 Windows 自启 watchdog | `启动/Startup/start-kanban.vbs` |
| data/tunnel-url.txt | 当前公网地址 | 运行时写入 |

**重启服务器**：`taskkill` 掉 node 进程即可，watchdog 会自动拉起；或直接重启电脑（自启会接管）。

## 六、数据备份与恢复（git）

项目根目录已是 git 仓库：
- `data/` 每次写入**自动提交**，数据有完整历史。
- 查看历史：`git log`（在 `project-kanban` 目录执行）。
- 回滚某次数据：找到对应提交，`git checkout <commit> -- data/projects.json` 后重启。

> `.gitignore` 已排除 `node_modules`、`auth.token`、`readonly.flag`、`tunnel-url.txt`（敏感/易变文件不入库）。

**手动打包带走**：直接压缩整个 `project-kanban` 目录（含 `node_modules` 与 `.git`），到别的电脑解压 → `node server.js` 即可运行。

## 七、故障排查 FAQ

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面打不开（本机） | 服务器进程退出 | 运行 `node watchdog.js`，或等自启拉起 |
| 公网链接 502 | 本机服务器挂了（隧道还在） | 重启服务器，链接不变 |
| 公网链接失效 | 重启电脑/隧道进程停止，快速隧道地址随机变 | 重新开隧道，新地址写入 `data/tunnel-url.txt` |
| 写操作弹「未授权」 | 令牌未输入/不对 | 输入 `data/auth.token` 里的令牌 |
| 只读模式改不了 | 已开启只读 | 点「🔓 解除只读」 |
| 数据改错想恢复 | 有 git 历史 | `git log` 找提交回滚 `data/` |
| 公式不更新 | 可能成环（>60轮） | 检查任务日期公式是否互相引用 |

## 八、参赛演示模式（`--demo`）★

用于比赛/对外演示：加载**脱敏数据集**（`data/projects.demo.json`，项目名与内部型号已 anonymize），且**免令牌**，评委打开即可随意点按、试修改，不污染真实数据。

```bash
# 演示模式（建议用独立端口，避免和正式 5180 冲突）
PORT=5191 node server.js --demo
```

要点：
- 演示数据写在 `projects.demo.json`，与正式 `projects.json` 完全隔离；演示中的任何改动不影响真实数据。
- 演示模式不弹令牌、不写 git 历史。
- 退出演示：直接关掉该进程即可，正式服务（`watchdog` 托管的 5180）不受影响。
- 重新生成脱敏数据：用同样结构的真实数据再跑一次生成脚本即可（见 `data/projects.demo.json`）。

> 对外参赛前，请确认运行的是 `--demo` 实例，且公网隧道指向该实例端口。
