# 汇报 / 周报 / 月报 + AI 总结 = 全局项目

四个视图（daily / weekly / monthly / panorama）**不依赖左侧选中项目**，无选中项目也渲染。

## 全局化机制

- `render()` 用 `globalViews` 分支，无视左侧选中项目。
- 项目集合 = `reportProjects(mode)`：全部进行中 + **归档项目仅在归档发生窗口内**：
  - 日报 = 当天
  - 周报 = 当周
  - 月报 = 当月
  - （按 `completedAt` 判断）

## AI 总结

- AI 总结按钮始终显示，`aiSummarize(mode)` 传全局项目。
- 后端 `/api/ai/summarize` 支持：
  - `{projects, mode}` 全局组合总结
  - `{project}` 单项目兼容（旧调用）
