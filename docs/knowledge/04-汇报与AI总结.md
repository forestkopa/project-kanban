# 汇报 / 周报 / 月报 + AI 总结 = 全局项目

四个视图（daily / weekly / monthly / panorama）**不依赖左侧选中项目**，无选中项目也渲染。

## 全局化机制

- `render()` 用 `globalViews` 分支，无视左侧选中项目。
- 项目集合 = `reportProjects(mode)`：全部进行中 + **归档项目仅在归档发生窗口内**：
  - 日报 = 当天
  - 周报 = 当周
  - 月报 = 当月
  - （按 `completedAt` 判断）

## AI 总结

- AI 总结按钮始终显示，`aiSummarize(mode)` 传全局项目。
- 后端 `/api/ai/summarize` 支持：
  - `{projects, mode}` 全局组合总结
  - `{project}` 单项目兼容（旧调用）

## AI 配置（/api/ai/config，2026-08-24 修复）

- 文件：`data/ai.json`（.gitignore 排除）。GET 返回 `{base_url, model, configured, key_masked}`（Key 只回掩码如 `sk-****abcd`）。
- **Key 管理规则**：POST 时 `api_key` 留空/未传 = **保持不变**（曾有个 bug：旧逻辑空串会清掉已配置 Key）；显式 `{clear_key:true}` 才清除；前端设置弹窗有「🗑 清除 Key」按钮。
- 前端打开设置：显示掩码状态 + placeholder「留空=保持不变」；填新值可更换。
