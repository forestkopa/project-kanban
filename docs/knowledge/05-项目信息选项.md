# 项目信息选项

## 工程师姓名 / 认证标签：纯手填

- **无下拉 / 无选项池**（已按用户要求移除，勿加回）。
- 勿恢复选项池 UI。

## 类型 / 产品类型 / 项目等级：可配置

- 存 `data/options.json`（gitignore 排除，换机需重配）。
- 支持新增 / 编辑 / 删除。
- 新增弹窗只留 **WPS 风格色板**（无自定义颜色行）。
- 等级 S/A/B/C/D/E/F 有默认色。

## 工程师类型：可增删

- 类型（硬件 / 结构 / 项目 / 测试工程师）存 `options.engineerTypes`，可新增 / 删除。
- 姓名行 = 类型标签 + 手填输入框。
- 保存为 `engineers: { 类型名: 姓名 }`，兼容旧 `hardware/structure/project` key。
