# 模板体系

## 无 JSON 模板导入

- 已删除 JSON 模板导入：`accept` 仅 `.xlsx`。
- 参考模版 Excel 导入 = 新建模板（取文件名、阶段作展示字段）。

## 模板卡片操作

- 可删除、可改名：`PUT/DELETE /api/templates/:id`。

## 导出参考模版

- 由内置模板生成的**甘特方言 Excel**：`GET /api/templates/reference-xlsx?tplId=`。

## 内置模板

当前 4 个：智能门锁 / 智能手表 / 智能摄像头 / 智能音箱（「社区共享-智能台灯」已删）。

> 注意：`templates.json` 为 demo / 正式双实例**共享**文件，公网评委改模板会影响正式版。
