# Excel 导出

## 技术栈

`xlsx`（导入）+ `xlsx-js-style`（带样式导出，生成真正 .xlsx）。所有 sheet 构建都在 `lib/xlsx-export.js`。

## 三张表与统一排版（v1.5.4）

| 表 | 入口 | sheet 构建函数 | 端点 |
|---|---|---|---|
| 计划表 | 项目内「导出 ▾ → 初版/最新计划」 | `planSheet()` | `GET /api/projects/:id/export?type=...` |
| 差异对比 | 项目内「导出 ▾ → 差异对比」 | `diffSheet()` | 同上 `type=diff` |
| 待办清单 | 「我的待办」页导出（日/周/月/下周） | `todoSheet()` | `POST /api/reports/todo-export` |

**统一观感（用户先看计划表截图，再要求待办照做，故三表必须一致）**：

| 区域 | 值 |
|---|---|
| 表头 / 标题 | 填充 `#1F4E78`，白字加粗微软雅黑，水平+垂直居中 |
| 网格 | 四边 `thin` + `#000000` 细黑线 |
| 对齐 | **全部列居中**（含任务列），无左对齐列 |
| 日期 | Excel **真日期** + numFmt `yyyy/m/d`（显示 `2026/9/13`，无前导零） |
| 功能高亮 | 待办逾期/顺延状态列红字加粗 `#E0241B`（唯一保留的着色） |

- 待办的历史配色（矢车菊蓝 `#1F3864` 表头 + 浅蓝 `B4C7E7` 边框 + 隔行 `F2F7FD` 斑马）**已废弃**；斑马去掉后项目分组靠「合并单元格 + 表格线」区分。
- 聚合报告 `buildReportXlsx()` 仍是旧配色，尚未统一（改动时按上表对齐）。

## 复用铁律（踩过的坑）

- **不能 read 回来再拼工作簿**：`xlsx-js-style` 读回时只回填 `patternType`，`alignment`/`font` 全丢。要一个文件多张表，直接复用 `planSheet()` / `diffSheet()` / `todoSheet()` 返回的 `ws` 对象（见 `tools/preview-todo-export.cjs`）。
- **测样式别用 read 断言**：① 直接单测样式函数（传 `ws` 对象读 `ws[A1].s.alignment`）；② 断言序列化 buffer 明文含 `horizontal="center"` / `style="thin"`。
- **`aoa_to_sheet` 必须 `{cellDates:true}`**：否则 `Date` 被转成序列号且 `t='n'`，只判 `t==='d'` 设格式会全部落空。`setDateFmt()` 双兼容 `t==='d'` 与 `t==='n'` 且 v∈(20000,80000)。
- **真日期用本地正午构造** `new Date(y,m-1,d,12)`：xlsx 序列号有分钟级浮点残差，零点遇时区偏移可能跨天。
- **真日期会撑爆自适应列宽**：`computeTodoCols` 按字符长度估算，`Date` 的默认字符串 40+ 字符 → 列宽顶到上限 40；必须对 `Date` 单独返回显示宽度（≈12）。
- **表头不在首行时 `setDateFmt` 要传 `startRow`**：待办是 0 标题 / 1 表头 / 2 起数据。

## 导出内容必须等于页面（v1.5.4 修）

后端二次过滤与前端 `collectTodos()` 语义必须完全一致，否则会出现「页面显示、导出消失」的静默不一致：

- ❌ 旧：`dueDate >= monIso` → 逾期任务（`dueDate < monIso`）被整批丢掉，`⚠ 逾期` 分支永远不可达。
- ❌ 旧：下周待办缺窗口上界 → 下下周到期的任务被一并导出。
- ✅ 现：已完成 / 无截止日期不进待办；今日/本周/本月 = 逾期 + 周期内到期（`dueDate ≤ 区间末`，且 `startDate ≤ 区间末`）；下周 = 顺延无条件纳入 + 到期日落在下周窗口内。
