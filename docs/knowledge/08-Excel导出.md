# Excel 导出（周报待办）

## 技术栈

`xlsx`（导入）+ `xlsx-js-style`（带样式导出，生成真正 .xlsx）。

## 周报待办导出

- 端点：`POST /api/reports/todo-export`
- 数据 = 当前周视图全局待办（与页面清单一致）。

## 配色（矢车菊蓝主题）

| 区域 | 颜色 | 说明 |
|---|---|---|
| 标题 / 表头 | `#1F3864` | 矢车菊蓝·着色1·深度50%，白字 |
| 全表网格 | `B4C7E7` | 标准细线 |
| 隔行 | `F2F7FD` | 浅蓝 |
| 逾期 | 红字 ⚠ | — |
| 里程碑 | ⚑ | — |

- 标题合并；项目列垂直合并。

## 聚合报告导出（2026-08-24）

- `/api/report/export`：单 sheet「聚合报告」，标题行仅「项目聚合报告」（无日期副标题）+ 按人汇总数据表（矢车菊蓝表头）。
- 曾试做完成率横向柱状条（单元格填充）后按用户要求移除，保持纯数据表。
