# 部署与双实例

多项目管理个人看板的本地运行与双实例架构。公网演示版（脱敏）与本机正式版（真实数据）**同时运行**，互不干扰。

## 启动命令

```bash
npm install
node server.js          # 正式版：端口 5181（真实数据，写操作需令牌 data/auth.token）
node server.js --demo   # 演示版：端口 5180（脱敏数据 + 免令牌，公网隧道指向它）
node watchdog.js        # 守护双实例：5180 演示 + 5181 正式，崩溃各自自动拉起 + 维护 Cloudflare 隧道
```

## 端口约定（勿改）

| 端口 | 版本 | 数据 | 令牌 | 用途 |
|---|---|---|---|---|
| 5180 | 演示版（`--demo`） | 脱敏 | 免令牌 | 公网评委用 |
| 5181 | 正式版（真实数据） | 真实 | 需 `data/auth.token` | 本机日常用 |

- 公网网址：每次重启变化，读 `data/tunnel-url.txt`（**始终指向 5180 演示版**，避免暴露真实项目名）。
- 重启流程：`taskkill /IM node.exe /F` → `node watchdog.js`（自动拉起双实例）。

## 共享文件注意

`templates.json` 为两实例**共享**文件：demo 评委在公网增删改模板会同步影响正式版模板列表（项目数据互不影响）。若介意，后续可把模板也按 demo/正式拆开。
