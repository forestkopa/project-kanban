# 多项目管理个人看板（智能硬件产品模板）

一个零依赖的本地网页应用，用于管理多个智能硬件产品项目。内置 4 份优秀产品模板，支持多项目切换、看板拖拽、任务增删改与完成跟踪。

## 启动

```bash
cd project-kanban
node server.js
# 打开 http://localhost:5180
```

（使用内置 Node 运行：`.../node/versions/22.22.2/node.exe server.js`）

建议通过 `watchdog.js` 运行（崩溃自动拉起 + 自动维护 Cloudflare 隧道）：

```bash
node watchdog.js
```

## 访问令牌（写操作鉴权）

- 所有**写操作**（新建/修改/删除/导入/只读切换）都要求请求头 `X-Auth-Token` 与令牌一致，否则返回 401；GET 查询不受限。
- 令牌在首次启动时自动生成，存放于 `data/auth.token`（启动日志也会打印）。
- 网页端首次执行写操作时会弹窗询问令牌，输入一次后记住（localStorage），后续自动携带。
- 令牌属敏感信息，请勿分享；如需更换，删除 `data/auth.token` 后重启服务器。

## 数据与备份

- `data/projects.json`：所有项目与任务（写队列 + 原子写落盘，崩溃不损坏）。
- `templates.json`：模板定义，可自行增删或改任务。
- 项目根目录是 git 仓库：`data/` 每次写入自动提交，数据有完整历史（`git log` 可回溯）。

## 开机自启

- `watchdog.js` 已注册到「启动」文件夹（`start-kanban.vbs`），登录 Windows 即自动运行：探测 5180 端口，服务器挂了自动拉起；同时保证 Cloudflare 隧道进程存活（新公网地址写入 `data/tunnel-url.txt`）。

## 加固（r51）

- 原子写 + 写入串行化（写队列）
- 写操作静态令牌鉴权 + 请求体 10MB 上限（413）
- 公式依赖 60 轮未收敛告警（疑似成环）
- xlsx 升级至官方 CDN 0.20.2（修复已知漏洞，API 兼容）
- 请求日志（时间/方法/路径/状态/耗时）
- 前端输入防抖（甘特图日期/工期/公式、项目开始）

## 功能

- **多项目**：左侧列表管理多个产品项目，每个项目独立看板与进度条。
- **模板建项目**：点「新建项目（从模板）」，选一份智能硬件模板即生成完整项目（阶段 + 任务）。
- **看板**：六阶段列（需求立项 → 设计开发 → 打样试制 → 测试验证 → 量产导入 → 上市运营），任务卡可拖拽跨阶段。
- **任务**：勾选完成、编辑、删除、指定负责人与工期。
- **统计**：总进度、任务数、已完成/进行中。
- **视图**：看板 / 甘特图（Excel 坐标 + 公式级联）/ 日历 / 全景 / 日报 / 周报 / 月度计划。
