## ② 到家 4 步部署

```
第1步 建虚拟机
极空间 → 应用中心 → 虚拟机 → 新建 → Linux 模板
  CPU 2 / 内存 4G / 磁盘 50G → Ubuntu 22.04 LTS
  网络选 bridge，物理网口选 网口1

第2步 装环境 + 拉代码（虚拟机内）
  curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt install -y nodejs git
  sudo useradd -m -s /bin/bash kanban
  sudo -u kanban git clone https://<PAT>@github.com/forestkopa/project-kanban.git /opt/project-kanban
  cd /opt/project-kanban && sudo -u kanban npm install

第3步 放数据 + 隧道凭据（关键！）
  sudo mkdir -p /opt/project-kanban/data /home/kanban/.cloudflared
  sudo cp app.db            /opt/project-kanban/data/app.db        ← 带数据库上 NAS
  sudo cp 2bbff070-*.json   /home/kanban/.cloudflared/
  sudo chown -R kanban:kanban /opt/project-kanban /home/kanban/.cloudflared

  改 config.yml：credentials-file 改为 /home/kanban/.cloudflared/2bbff070-....json

第4步 起服务
  sudo cp deploy/kanban.service deploy/kanban-demo.service deploy/cloudflared.service /etc/systemd/system/
  sudo systemctl daemon-reload && sudo systemctl enable --now kanban kanban-demo cloudflared
```

## ③ 验证（重要！）

```
systemctl status kanban kanban-demo cloudflared      # 三个都 active
curl -s http://127.0.0.1:5181 -o /dev/null -w "%{http_code}"   # 200
```

然后**关掉本机 Windows** → 用手机流量打开 `https://kanban.forestkopa.top` → 能开 = 成功
